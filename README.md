# ⚡ MagnetX — Direct Magnet & Torrent File Extractor

> **Instant Magnet & Torrent Extractor, Streamer, and Direct Downloader**  
> No cloud limits, no storage subscriptions, no waiting. Paste a link -> Extract files directly -> Download as many as you want!

---

## 🚀 What Makes MagnetX Perfect for You

- **No Cloud Limits or Quotas**: You don't have to worry about Seedr's 2GB cap or cloud storage fees. Download as many torrents and files as you want directly.
- **Direct File Extraction from Magnet Links**: Paste any magnet link or drop a `.torrent` file to immediately resolve the file tree.
- **Automatic Multi-part Archive Unpacking**: Automatically extracts `.zip`, `.rar`, `.7z`, `.tar.gz`, `.tar.bz2`, and multi-part split RAR files (`.part01.rar`, `.part1.rar`, `.r00`) into organized folders so you get the actual media/files immediately!
- **Direct HTTP Download Links for IDM & 1DM**: High-speed resumeable direct download links with multi-threading and range requests.
- **"Copy All Links" in 1 Click**: Copies all extracted direct download links to clipboard so you can paste them all at once into Internet Download Manager (**Tasks -> Add batch download from clipboard**).
- **"Download All as ZIP"**: One-click streaming ZIP download of the entire torrent folder with zero disk overhead.
- **In-Browser Video & Audio Player**: Stream movies (MP4, MKV, WebM) and music with instant seek and automatic `.srt` to `.vtt` subtitle loading.

## 💻 How to Run

### 1-Click Launch (Windows)
Double-click `start.bat` or run in terminal:
```powershell
npm start
```

Then open your browser at:
👉 **`http://localhost:3000`**
